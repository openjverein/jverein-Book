# Filterprofil

Für den Filterbereich in den Liste Views können Filterprofile angelegt werden. Über den "Filter-Profile" Button öffnet sich folgender Dialog.

<picture><img src="https://github.com/openjverein/jverein-Book/raw/master/assets/403_FilterProfileDialog.png" alt="" /></picture>

Neben dem ausgewählten Profil werden die aktiven Filter Felder angezeigt, die im Profil gespeichert sind.

Es gibt folgende Buttons:
* Hilfe: Ruft diese Hilfe auf
* Neu: Erstellt ein neues Profil mit den gerade aktiven Filterkriterien 
* Speichern: Überschreibt das ausgewählte Profil mit den gerade aktiven Filterkriterien 
* Löschen: Löscht das gerade ausgewählte Profil
* Anwenden: Übernimmt die Werte aus dem ausgewählten Profil in den Filterbereich der aktuellen Anzeige
* Abbrechen: Schließt den Dialog
